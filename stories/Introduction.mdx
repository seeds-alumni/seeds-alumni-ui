# SEEDS同窓会の共通 UI（@seeds-alumni/ui）

SEEDS同窓会のサービスで共通に使う、デザイントークン・CSS・React の骨組みの部品です。

- **画面の型**：新しい画面はここから始めます（会員向けのページ・ログイン・フォーム・ダッシュボード・一覧・詳細）
- **部品**：React の部品を props を変えながら確かめられます
- **クラス**：React を使わない画面（素の HTML）でも同じクラスで組めます
- **カタログ**：原則・トークン・クラス・部品・ルールの一覧（`docs/catalog.md`）
- **デモ**（新しいタブで開きます）：<a href="/demo/react" target="_blank" rel="noopener">画面の型のデモ（React）</a>・<a href="/demo/" target="_blank" rel="noopener">素の HTML のデモ</a>
